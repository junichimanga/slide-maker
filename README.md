# スライドメーカー

AI でスライドのベースを作り、あとから Canva のようにテキストや図解を編集できるローカルツールです。

## セットアップ

1. `.env.example` をコピーして `.env` を作り、Claude API キーを入れる

   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```

2. 起動

   ```
   npm run dev
   ```

3. ブラウザで http://localhost:5180 を開く

`.env` を変更したときは、開発サーバーを再起動してください（起動時にしか読み込みません）。

## 使い方

- **AI生成タブ**: テーマと枚数、テーマ色を指定して「スライドを生成」。30秒〜1分ほどで構成・文章・図解が入ったスライドができます。
- **編集**: 要素をドラッグで移動、角のハンドルでサイズ変更、テキストはダブルクリックで直接編集。図解のボックスや矢印も1つずつ動かせます。
- **プロパティタブ**: 選択した要素の文字サイズ・色・配置・枠線などを調整。
- **上のツールバー**: テキスト・四角・円・矢印の追加。
- **左の一覧**: スライドの追加・複製・並べ替え・削除。
- **画像タブ**: 画像の内容とスタイルを指定して「画像を生成してスライドに置く」。Codex CLI（ChatGPT サブスク）の画像生成を使うので API キーは不要です。1枚 1〜2分。PC にある画像ファイルの配置もここからできます。
- **PDF書き出し**: 全スライドを 1 枚ずつ画像化して PDF にします。
- **JSONで保存 / JSONを開く**: 編集途中の状態をファイルに保存・復元。ブラウザにも自動保存されます。

## ショートカット

| キー | 動作 |
|---|---|
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| Delete | 選択した要素を削除 |
| Ctrl+D | 選択した要素を複製 |
| Esc | 選択解除 |

## 画像生成の前提

- Codex CLI がインストールされ、ChatGPT アカウント（Plus 以上）でログイン済みであること（`codex --version` と `codex login status` で確認）。
- 生成は `codex exec` を裏で呼び、`~/.codex/generated_images/` に出た PNG を `public/images/` にコピーしています。非公式の使い方なので、Codex 側の変更で動かなくなる可能性があります。
- 使うモデルは `.env` の `CODEX_MODEL` で変えられます（省略時 `gpt-5.5`）。

## 仕組み

- AI は座標を出しません。`src/spec.ts` の構造（レイアウト種別・タイトル・箇条書き・図解の項目）だけを JSON で返し、`src/compile.ts` のテンプレートが座標やサイズに変換します。
- 図解（流れ / 循環 / 分類 / 階層）は四角・円・矢印・テキストの組み合わせとして生成されるので、生成後に 1 パーツずつ編集できます。
- Claude API の呼び出しは `server/generate.ts` で行い、Vite の開発サーバーが `/api/generate` として中継します。API キーはブラウザに渡りません。

## 主なファイル

| ファイル | 役割 |
|---|---|
| `src/types.ts` | スライド・要素のデータ型 |
| `src/spec.ts` | AI が返す構造の定義（zod） |
| `src/compile.ts` | 構造 → 座標付き要素へのレイアウト変換 |
| `src/themes.ts` | 配色テーマ |
| `src/components/SlideCanvas.tsx` | Konva によるキャンバス描画・編集 |
| `src/components/PdfExporter.tsx` | PDF 書き出し |
| `server/generate.ts` | Claude API 呼び出し |
| `server/image.ts` | Codex CLI による画像生成と手持ち画像の保存 |
| `src/components/ImagePanel.tsx` | 画像タブの UI |
| `public/images/` | 生成・配置した画像の保存先 |
